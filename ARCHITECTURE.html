Keeping this page real

  1. When a module moves from planned to built, its box changes from the dashed grey style to the solid green one, and its text updates from "Not built yet" to what it actually does, in both Section 00's overview and its own deep section.
  2. When a new piece gets added (a new module, a new external service, a new database column), it gets a new box or a new table row where the equivalent already lives, not a note bolted onto an unrelated section.
  3. When an Azure resource in Section 06 actually gets provisioned, its box moves from dashed grey to solid green, exactly like every other "not built yet" box on this page, and its azure-card below gets the real resource name and region.
  4. Whenever this page changes, the same day's dev-log/raw/YYYY-MM-DD.md entry should say so, same rule as every other real change on this project.
